SW Requirements

This file contains the software requirements for the lobster-doxygen tool.

Attribute Name

Attribute Value

Description

sw_req_no_trace

Attribute Name

Attribute Value

Description

The software shall output a warning and create a lobster common interchange file if doxygen XML contains no traces.

Valid Status

VALID_STATUS.valid

Note

This is required to detect untraced sourcecode, but doesn’t break any toolchain flow.

sw_req_valid_id

Attribute Name

Attribute Value

Description

The software shall consider TRLC identifiers matching the format [a-zA-Z][a-zA-Z0-9_]* as valid and ignore additional doxygen content when extracting requirement identifiers.

Valid Status

VALID_STATUS.valid

Note

TRLC identifier format is defined in the language reference manual at https://bmw-software-engineering.github.io/trlc/lrm.html\n Note that identifiers of package and requirement are concatinated via ‘.’.

Derived

N/A

Verification Criteria

sw_req_invalid_input

Attribute Name

Attribute Value

Description

The software shall output a warning if the doxygen xml contains no valid TRLC identifier in an entry of the tracing table.

Valid Status

VALID_STATUS.valid

Note

Identifiers are matched to trim possible comments or else parsed by doxygen. If no valid identifier is present, an error must be present in the annotations.
