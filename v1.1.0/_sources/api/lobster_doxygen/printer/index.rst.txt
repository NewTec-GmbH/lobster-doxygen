.. py:class:: Printer

   The printer class.
   Prints errors, warnings and infos. Infos and warnings are only printed, if
   verbose mode is set.


   .. py:method:: print_error(message: str) -> None

      Print error message to standard error stream.

      :param args: The error information that will be printed.
      :type args: str



   .. py:method:: print_info(message: str) -> None

      Print the information to the console standard output.

      :param args: The information that will be printed.
      :type args: str



   .. py:method:: print_warning(message: str) -> None

      Print warning message to standard error stream.

      :param args: The warning information that will be printed.
      :type args: str

      :classmethod:


      Set verbose mode for all instances of the class.
